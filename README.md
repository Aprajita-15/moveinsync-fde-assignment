## About this assignment

This report analyses publicly visible Play Store feedback for MoveInSync's employee commute app and turns the main reported pain points into a practical improvement plan.

---

## What's in this repository

- `Movei.pdf` — Full analysis report (Play Store rating analysis, root-cause hypotheses, 30-day action plan)

---

## Key findings

- Login and OTP friction is the highest-impact issue — employees who can't sign in can't book their ride
- Booking confirmation clarity needs improvement — one reviewed comment described booking on the wrong date and missing their cab
- Pickup notifications arrive too late — critical for a time-sensitive commute app
